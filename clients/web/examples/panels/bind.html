A bound panel drives a synth directly: the values bypass this script. The low-latency interactive path: a control bound to a running synth sends its value straight to the audio server on every turn, with no round trip through this page's script. An unbound control would instead emit a /gui_event back here; binding swaps that for a direct /node_set to the server. The controls are built from the def's own control objects, so each widget already knows which control it drives and the window binds in one verb — win.bind(synth) — instead of one hand-typed name per widget. The two shapes a control signal comes in are the two buttons. A button's press is the event, and its mode says which of the two pointer primitives reaches the server: the default "gate" sends its on at the press and its off at the release, so the value lasts exactly as long as the button is held; "press" sends one message and nothing after it — the bang. A widget cannot make a value instantaneous, so the bang is only a bang against a control that returns to zero on its own: a trigger (rate: "tr"), which the server resets after one block.
