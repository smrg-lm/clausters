A code element holds a text drawn in the monospaced face, with its line numbers and the line the caret is on, colored by its syntax (language names it: keywords, names, strings and comments each in a color of the theme, kept as you type), and edits it as a code editor does: click to place the caret (two clicks a word, three a line, a press on a line's number the whole line), drag or Shift and an arrow to select, Ctrl+X, Ctrl+C and Ctrl+V, Ctrl+Z to undo a run of typing at once. Tab indents and Shift+Tab takes a level off; Enter keeps the line's indentation and adds one after a line that opens a block. Tab stays in the editor: Ctrl+Tab moves on.

It types code as code is typed: a bracket or a quote brings the one that closes it, which you then type over, and Ctrl+/ comments the lines selected (again, uncomments them). Put the caret by a bracket to see its pair marked, and select a word to see where else it stands. Ctrl+F opens a bar along the bottom to find and replace: Enter finds the next match, Shift+Enter the previous, Tab goes to the replacement, and Escape closes it; F3 goes on finding with it closed. Ctrl+Alt+G goes to a line.

Shift+Enter evaluates the line (or the selection) and Ctrl+Enter the block, the whole def or with under the caret, moving past it: the editor runs nothing, it tells whoever owns it, and here that is this page, which writes what it was asked to evaluate to the post window. Ctrl+. asks for an interrupt.

Language help is asked of the owner too: a name begun (or Ctrl+Space) asks for completions, which this page answers with the names the text already holds, so typing ch offers chord; walk them with Up and Down and take one with Enter. A session would answer from what it holds, and answer signature and inspected as well (the parameters of a call, what a name is); this one leaves those unanswered.

Under it is a post window with what a session might have printed; drag the divider between the two to give one more room.
