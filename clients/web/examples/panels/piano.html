The web port of the Python client's panels/piano.py: a piano keyboard, and the voices it plays. The piano widget shows five octaves with the 88-key range marked; the strip above the keys is its navigation surface — drag it to pan, wheel over it to zoom. Playing emits MIDI-shaped events (note with pitch, velocity, state and channel), and this page maps each one to a server voice: state 1 spawns a held synth, state 0 closes its gate and the release tail frees it. That mapping is the point. The other path — the widget bound to a voice the host instances, with no script between the key and the sound — is what examples/panels/piano/index.html boots as a standalone bundle.
