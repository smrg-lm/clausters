Build a GuiDef, read a widget back — the smallest round trip over the widget protocol. A GuiDef is built exactly the way a SynthDef/GraphDef is: a tree of {id, type, ...props, children} nodes serialized to JSON and sent in one /gui_def message. The host registers the tree and answers /gui_query with /gui_info. The children are named, not numbered: open assigns each a fresh id and hands back a handle that resolves the names.
