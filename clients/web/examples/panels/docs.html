A docs element is given the books it shows (books, each one's table of contents) and their documents (documents, the Markdown of each by its path), and draws them: a start page listing every book, a book's contents, a document with its headings, lists, a table, a quote and a code block in the colors of its syntax, with a button that copies it. Click a chapter to open it, a link to go on to another document at its heading, and the arrows at the top left to go back and forward; the strip says which book and chapter the page is. Ctrl+F finds in the page (Enter for the next match) and Ctrl+Shift+F searches every document.

A link out of the documentation is reported to this page ("link"), which writes it below; a program would open it. Help on a name is one set: docs.set({ help: { name } }) opens the section that is it.
