An editable text field types an OSC message straight to the server. You click into it, type, move the caret (word-wise with Ctrl), select, delete — a character, or a whole word with Ctrl+Backspace / Ctrl+Delete — and cut/copy/paste. What it emits is a string, delivered exactly the way a slider delivers its float: as a /gui_event on every edit, never gated on Enter. This page consumes that stream, parses each line into an OSC address plus typed arguments, and sends it to the audio server. Because the send is ungated, editing the message is live: it seeds a running synth's /node_set <id> freq 220 and, as you edit the number, the pitch follows what you type digit by digit. A half-typed or unknown message is simply ignored by the server, so type freely.
