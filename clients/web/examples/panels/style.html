Style: theme groups, per-widget accents, and the two paint props. The host draws every chrome color from one theme — a table of named roles (background, panel, text, accent, …) — and the customization is the same partial table at every level, each overlaying the previous: 1. The host's own table (host.theme({…}), the /gui_theme verb): one look for the whole host. This page warms the accent with it. 2. A theme group (the theme prop on a container): a partial table scoped to that subtree, recursive by construction — a nested group overlays the inherited table, not the default. 3. The color prop (any widget): the single-color shorthand, re-seeding just the roles that carry the widget's function. Overlays resolve when a def arrives or a set changes them — never per frame — so a styled window costs exactly what a plain one costs. Two more props shape the drawing rather than its color: opacity (0–1) fades a widget and, like a theme group, multiplies down its whole subtree; radius rounds the corners of the boxes a widget draws, clamped to half the shorter side of each.
