A GuiHost is a handle on a host, and there are two verbs that reach one: boot, for a host that is not there yet — in a tab that is the wasm host in this document, and the handle that booted it owns it. attach, for a host already running — one another handle brought up. It verifies that someone answers there and takes no ownership: stop lets the client go and leaves the host standing, windows and all. This page plays both parts at once, so the difference is visible in one run: it boots a host, attaches a second handle to it, and each handle opens a window of its own on the same host. Stopping the attached handle leaves both windows on screen; the host goes down with the one that booted it. Two handles naming widgets on one host want a share of the id space (the same arithmetic as two clients on one audio server), or both would allocate the same ids and the second would silently take the first's widgets.
