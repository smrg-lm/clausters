The web port of the Python client's chain.py: an FFT → PV → IFFT chain. fft analyses a bright source into a spectral frame, each pv* transforms that frame in place, and ifft overlap-adds it back to samples. No buffer is allocated — the frame is synth-private scratch on the server — so the chain is just wired UGen to UGen, and only fft names the window size, which the server propagates down the chain. The score is two seconds of both, freed by a routine that closes each gate -- left is the raw noise, right is the spectral low-pass, so the difference is the whole point of listening to it. The render happens in the in-page engine: no server process, no socket, and nothing to unlock until you ask to hear it.
