The web port of the Python client's chain.py: an FFT → PV → IFFT chain. fft analyses a bright source into a spectral frame, each pv* transforms that frame in place, and ifft overlap-adds it back to samples. No buffer is allocated — the frame is synth-private scratch on the server — so the chain is just wired UGen to UGen, and only fft names the window size, which the server propagates down the chain. Where the Python example renders the effect offline, this one runs it live: pvBrickWall's wipe is a lagged control, so dragging it band-limits the noise in the spectral domain while you listen — positive wipes zero the top fraction of the bins (a low pass), negative ones the bottom (a high pass), and 0 passes everything. Beside it, pvMagFreeze holds the magnitudes of whatever frame was passing when you press it, so the spectral envelope stands still while its phases keep running. Everything sounds through the in-page engine: no server process, no socket. Swapping to a --ws server is the one line marked below.
