a playable piano as one web component: the bundle below (authored by make_bundle.py with the Python client) opens a virtual keyboard whose keys the GUI host maps to server voices on the wasm engine in this tab — a /s_new per key press, a gate release per key up, no server process, no script in between. Drag the strip above the keys to pan the MIDI range, wheel over it to zoom; grayed keys are outside the instrument's active range. The power button is the autoplay gesture.
