Linked editor views: one navigation group, several lanes. The classic editor layout is one item with parts: a waveform lane and a spectrogram lane of the same sound under one time axis, with one selection. This page renders a stereo phrase offline and composes the two heavy views over that single payload with link: 1 — the shared navigation group: zoom, pan and drag-selection on either lane move both (the group owns the horizontal view, the selection and the playhead; each member keeps only its own vertical window); the script sees one event stream, carrying the interacted lane's id rather than one event per member; a set of viewStart/viewLen, selStart/selLen or playheadAt on any member applies group-wide; and membership is live — setting link moves a lane between groups, a negative one unlinks it.
