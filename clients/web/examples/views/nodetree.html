A live node-tree view: the GUI mirroring the audio server's node graph. A nodetree widget shows the server's tree — its groups, synths, def names and control values — and keeps it current: the GUI host mirrors the tree over its client leg (/group_queryTree), refreshing the moment a node is created or freed (/node_start//node_end) and on a low-rate poll that catches /node_set changes. Nothing in this page pushes the tree to the GUI; the host reads it from the server itself, which is what session.gui() wires up.
