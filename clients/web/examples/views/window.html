The first pixels: a navigable waveform, fed by a source. It builds a view holding a label and the heavy waveform, feeds it a generated signal through a source, and opens it on the GUI host. The host draws the waveform; the wheel zooms toward the pointer, left-drag pans, R resets. Then the source is pointed at other samples and the same view redraws — a source is addressable, so what it holds can change without the tree being rebuilt. No audio server is involved — the signal is generated here — so this brings up only the GUI host.
