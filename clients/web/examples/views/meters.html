The web port of the Python client's views/meters.py: a meter and a scope over one control bus, above a waveform of a server buffer. This page names what to look at and draws none of it. A GuiDef says gui.meter(bus), gui.scope(bus), gui.waveform({ buffer }) — a bus number and a buffer number — and the GUI host subscribes, measures and paints: the trigger that makes the trace stand still, the peak columns and the join that inks an edge are all its, out of the same clausters-core the server computes with. There is no canvas in this page and no arithmetic over samples; the whole of the client's part is the tree below and the bus.set that animates it.
