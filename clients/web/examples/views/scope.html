A triggered audio-rate oscilloscope over a server audio bus. The GUI's scope widget names a bus and a rate. At audio rate (the default) it is a real oscilloscope, showing the actual samples of a live signal with a level trigger that holds the trace still; at control rate (see meters.html) it plots a control bus's history one sample per frame. This page only names the bus. Behind it the GUI host asks the server to record that bus and reads the newest window from it each frame, and stops the recording when no open view is drawing it.
