The web port of the Python client's views/editor.py: the editor-grade views, and the clipboard round trip. A phrase is bounced offline, installed into a server buffer, and the GUI host draws it as a waveform and a spectrogram. A plain drag selects, Shift+drag pans, the wheel zooms and r resets; each selection comes back to this page as a /gui_event. Ctrl+C on the waveform, then Ctrl+V: hear exactly what was copied. Copy is a read, so the host does it alone and nothing arrives here. Paste changes data, which the host does not own, so it arrives as a request with the clipboard travelling beside it — the kind, the document, and the samples as one little-endian f32 blob. This page puts the block in a buffer of its own and plays it once; nothing is written back over the take. Nothing is drawn by this page: the canvas below belongs to the host, as it does in every view this client opens. Everything runs on the in-page engine: no server process, no socket.
