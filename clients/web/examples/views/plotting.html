Quick looks with the free-standing plot — defs, envelopes, sequences. plot is the visual sibling of play: one verb that opens its own window for whatever you hand it, resolving a GUI host lazily on first use (no audio server involved — a def is rendered offline). The returned handle retunes the display live and closes the window. This is a sequential visual tour: each window appears alone, says so in the log, makes one live change and comes back (view, pinned axis side, frequency scale — all through win.set, no re-render), and closes before the next one opens. While a window is up, hover the trace: a hairline names the exact sample under the cursor.
