Plotting an offline render's output: the static plot view. A plot is the lightweight counterpart of the heavy waveform: it draws a signal once (a line, or a min/max envelope when there are more samples than pixels) with no zoom or pan. Here the signal is produced offline, by the renderer, with no server and no audio device, then handed to the GUI host as a bulk payload — the samples never ride OSC argument by argument. So no audio server is involved — the audio was already rendered offline — and this brings up only the GUI host.
