Two servers side by side, and the pair of verbs that reach one. A Server is a handle over a carrier, and the carrier says what bringing it up means. boot is for a server that is not there yet: it starts what the carrier points at and owns it, so quit stops it. attach is for one already running — it verifies that someone answers, reconciles this handle's allocators with the real server's capacities, and takes no ownership: close lets go and leaves it standing. Two engines run here, each its own AudioContext and its own node, bus and buffer space, and you will hear both — a fifth, one note from each.
