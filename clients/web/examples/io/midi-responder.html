Drive the server from a MIDI keyboard — a MidiFunc turning notes into synths. The web port of the Python client's examples/io/midi_responder.py, and the MIDI counterpart of responders.html: a MidiFunc listens on a MIDI input port and dispatches each message to a callback. Here a note-on starts a synth and the matching note-off frees it — the client-side mirror of the server's own direct MIDI path (a server can be played by MIDI it receives itself, or by a client that listens to MIDI and forwards /synth_new). The one difference from the script, and it is the platform's: the Python client opens a virtual input port named clausters-in that you then wire a keyboard into. Web MIDI creates no ports — it hands a page the ones that already exist, after asking your permission — so this picks one from that list instead. Plug the keyboard in first, press connect, allow MIDI, choose the port, and play. Everything below runs on the in-page engine: no server process.
