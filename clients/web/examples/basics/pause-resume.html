The web port of the Python client's pause_resume.py: a paused node is not a freed one. node.pause() / node.resume() are the /node_run command. A paused node stays in the tree and keeps its state — silent and free of CPU — and resumes exactly where it left off, which is what makes the PAUSE_SELF done action non-terminal: a synth parked by its own envelope can be brought back with a /node_run 1. The drone below has no envelope, so it runs until it is paused or freed, and its phase is what you hear survive the gap. Query the node tree while it is paused: it is still there.
