The web port of the Python client's typed_controls.py: a control's type is part of the def. freq carries a lag of 0.12 s, so a new note glides to pitch instead of jumping — a portamento lead. gate is a trigger (rate: "tr"): a /node_set gate 1 holds for one block and the server resets it, so every set re-plucks the percussive envelope; a plain control gate would stay at 1 and never trigger again. detune is drawn once with rand — an ir scalar, frozen for the synth's life, so each new lead is a little different. The lag and the trigger only make sense on a synth that outlives its notes, which is what one persistent node driven by a routine gives, rather than an /synth_new per note.
