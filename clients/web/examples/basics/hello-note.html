The simplest possible sound: open a server, play a note. No Session, no clock wiring. boot adopts the server as the default session, so play finds it on its own. A bare event outside any clock plays immediately and frees itself after its sustain, and the phrase under it runs on the default session's clock — created and started for you. Nothing is sent first: default is the server's own built-in instrument, and it carries the gated envelope that makes a note end.
