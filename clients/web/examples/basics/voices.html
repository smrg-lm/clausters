A Voices node is one instrument in the tree, played by MIDI, by a pattern and by the client -- and a note never makes a node. An instrument is a node that reads an event bus. Voices holds eight voices of the built-in default, all built with the node, and its notes control names the event bus it reads -- as a node's in names the audio bus it reads. Whatever writes that bus plays it: a note takes a free voice, resets it and starts it; its end closes the voice's gate. Three writers reach the same eight voices, one after the other: MIDI -- midiBind routes channel 0 to the bus, and the chord arrives as MIDI 2.0 packets (midiUmp), the path a keyboard on a native server's MIDI input takes; a pattern -- an Event whose instrument is the node is one of its notes, so pbind({ instrument: keys, ... }) plays it, and a pvoice line on it is one held voice; and the client -- busEvent writes notes on the bus from a routine, at its logical beat. The node count is printed at the end: one node, however many notes played.
