A Session bundles a server, a clock and (if you ask for one) a GUI host into the handle a piece is written against. Adopt one as the page's default and the ambient verbs work with nothing wired: play sounds whatever you hand it — an event, a plain object of event keys, a generator, a pattern, a def, a timeline, a buffer — and a bare new Synth(…) reaches the session's server without naming it. The carrier is the one line that knows about one. This page opens the session on the in-page engine; Session.connect(url) would open the same session on a clausters --ws server, and nothing below would change.
