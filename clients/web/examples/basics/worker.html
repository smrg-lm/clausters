A session in a worker, on this page's engine. The page boots the engine and keeps it: its AudioContext, its audio, the gesture that starts it. A worker runs the code that plays (worker-session.js), and the page gives it a link to the engine (engine.link()), a port the worker opens a session over with Session.live(port). The worker is one client of the engine with ids of its own, and what it sends goes to the engine directly, not through this page's thread. What the worker gives: its code can be stopped. Press hang and the worker enters a loop that never yields, so its clock never wakes again; the page goes on answering. Terminate ends the worker, lets its link go and silences the engine from the page (Server.panic), since what the worker left sounding has nobody to stop it. The engine is still running: start again gives a new worker a new link onto it. The Python client's counterpart is a script in a process of its own, attached with Session.live to a server something else booted; the worker is the same separation inside a page. Build first (./build.sh from clients/web), then serve this directory and open the page.
