The web port of the Python client's freeze.py: freeze a generative piece and hear that it continued rather than restarted. A def running a stochastic process is the case no DAW transport covers. A DAW's audio exists before you press play, so a position is an index into it; here the audio is produced as it sounds, so the piece's position is the state of the running nodes and no number moves it. The only thing a transport can honestly do to such a piece is stop it and let it carry on. server.transportGroup(group) binds a group to the server's transport, and from then on server.transportStop() does three things at the same sample: it freezes that subtree with every node's state intact, it stops the transport clock, and it freezes the queue of anything scheduled against that clock. server.transportPlay() undoes all three. The page has to stop too, and that is the second half. A clock's beats come from a timebase that only decides how long to sleep, so a page whose server froze would keep advancing beats into a piece that is not moving. clock.freeze() holds the beat instead, and clock.thaw() shifts the pacing origin so the frozen seconds are not part of the piece. What to listen for: at the pause the texture stops dead, mid-gesture, and on the resume it picks up from exactly there — not from the top. Run it twice: the two takes are the same piece interrupted, never two different pieces.
