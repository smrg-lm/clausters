A conductor's play/stop/locate driving several clients' playheads in lockstep. The server hosts a shared transport with a DAW-style rolling state (play / stop / position). A conductor (any client) calls transportPlay / transportStop / transportLocate; the server broadcasts the new state to every notify client, and each client's followTransport rolls, halts or seeks to match. The server only broadcasts transport control — it never schedules audio; each client rolls its own playhead on the shared grid. When the followers also lock to the server's sample clock (as here) the alignment is sample-exact. Two independent followers run in this one page, each taking its own share of the client id space so two of them never hand out the same node id.
