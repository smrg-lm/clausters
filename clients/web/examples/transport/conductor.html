A conductor's play/stop/locate driving several clients' timelines in lockstep. The server hosts a transport: a governed group, a clock that freezes with it and a position a locate moves. A conductor (any client) calls transportPlay / transportStop / transportLocateSample; every client whose timeline is on that transport (timeline.transport = server) rolls, freezes and re-cues to match. The server broadcasts transport control and owns the time -- it plays no notes of its own: each client plans its own items onto the transport's clock, which is what makes a freeze hold them and a locate move them. Two independent followers run in this one page, each taking its own share of the client id space so two of them never hand out the same node id.
