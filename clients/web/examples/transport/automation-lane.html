The web port of the Python client's automation_lane.py: automate a synth control with a break-point curve. An Automation is a control curve that drives one or more [node, control] targets. It is rendered as a control vector: the curve is discretized on the server into a control buffer (/buffer_gen "env", evaluated through the same envelope-shape math the EnvGen UGen plays), and a small control synth reads that buffer onto a control bus which the target follows via /node_map. The curve is the same Env the bpf editor round-trips (envToPoints / pointsToEnv), so a drawn envelope and a played automation are one object — which is why the editor is right here below: draw the glissando, then play it. A single sustained sine has its pitch swept by the lane, with no per-note retriggering. Edit it: drag a point to move it, drag a segment vertically to bend its curvature, Ctrl+click to add a point (Ctrl+click a point to remove it). Every edit comes back as a points list, which is what the next play the lane rebuilds the curve from. Where the Python example renders offline to a WAV, this one plays live: a page has no offline drive.
