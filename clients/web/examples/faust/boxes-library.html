The box API: Faust library DSP glued together from the page. The web port of the Python client's examples/faust/boxes_library.py — same instrument, same phrase, the same calls in the same order. defs.boxes reuses the Faust libraries without transcribing them: box.faust(…) compiles any Faust expression into a Box that composes like a primitive. This example builds an instrument out of three library pieces — an oscillator (os.osc), a lowpass (fi.lowpass) and a stereo reverb (re.stereo_freeverb) — wired to sliders and arithmetic built here, then renders a short phrase offline. The two application stages at work, kept apart in the syntax:
  • arguments to box.faust are evaluation-stage, spliced into the Faust source text (the filter order 3, the reverb's structural parameters);
  • arguments to .call(…) on the resulting box are composition-stage, boxes wired to its signal inputs (the sliders, the previous stage).
The one difference from the script, and it is the platform's: a page has no filesystem, so where the script writes out.wav this offers the take as a download. Everything else is the same call. And the compiler is in the tab — the render compiles the score's Faust defs with libfaust-wasm in the NRT worker before it starts, so no server process is involved anywhere. Needs ./build.sh in clients/web first (dist/ is git-ignored); serve it over HTTP (python3 -m http.server) and open /examples/faust/boxes-library.html.
