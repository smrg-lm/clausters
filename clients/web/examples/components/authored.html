A bundle written here, mounted here

The writer emits a whole bundle — the def payloads, the GuiDef template, the manifest, the generated module — and on a page it emits them as text rather than to a directory. The mount takes that text: nothing is served, nothing is fetched, and what draws below is the same instrument a saved directory would have produced.

It is already drawing: mounting is two phases, and the first one needs no audio at all. Press sound it (the browser wants one gesture before an AudioContext) and then turn the knob: it is bound straight to the node the bundle's boot list instantiated, and the meter draws the LFO the def publishes on its own bus.
