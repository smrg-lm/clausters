The web port of the Python client's offline_render.py: a piece rendered faster than real time in this tab, with no audio device and no server anywhere. The third carrier is not a carrier at all. Session.nrt() gives a Server whose connection writes time instead of waiting for it: every command a piece emits is accumulated as a timestamped score, and session.render() drains the clock — logically, with no sleeping — and hands that score to the engine's own renderer, the same wasm that makes this page's sound, running as fast as the machine manages. The session is its own random context, so its seed reproduces every random draw (the Pwhite here) end to end, independently of any other session. The server's seed is a separate one, reported as stats.seed: hand it to the next render and the take repeats sample for sample. Nothing here needs a gesture except hearing it: an offline render has no AudioContext to unlock. That is the point of it — the piece is evaluated, not performed. Needs ./build.sh in clients/web first (dist/ is git-ignored); serve it over HTTP (python3 -m http.server) and open /examples/buffers/offline-render.html.
