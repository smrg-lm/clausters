Two ways to hold a sound still

An interactive text: the instruments are in the prose, not beside it.

Everything below runs in this tab. There is no server process and no scripting client — each instrument is a bundle, a small directory of persisted defs and one GuiDef, mounted as a custom element. The page loads the audio engine, the GUI host and the mount; the builders that wrote these files ran once, on a laptop, in Python.

Press power on either instrument to start the audio for the whole page — the browser wants one gesture, and one is all it takes. After that each instrument has its own play switch in its header: they all sound at once otherwise, and stopping one pauses its whole graph rather than merely turning it down.

A graph, and its surface

The first instrument is two synths wired through a private bus: an FM voice into a tremolo. What the knobs touch is not the synths but the surface the GraphDef declares — freq, ratio, bright, rate, depth, amp — so the control panel is the instrument's own vocabulary rather than a list of its parts.

Here is the same bundle again. Nothing was written twice: the defs were sent to the engine once, and this second instance was allocated its own node and its own bus. The only thing that differs is an attribute in the markup, freq="110", an octave below its sibling — so the two sound together rather than in unison.

A keyboard, with no script behind it

The second instrument is a different bundle in the same page, sharing the same engine. Its keys are not events a script listens for: the host itself spawns one server voice per held key and gates it on release. The meter under the keys reads the envelope the voice publishes — on a bus that, again, belongs to this instance alone.

Scroll past an instrument and it stops working: a canvas outside the viewport is skipped on the frame tick, and its buses leave the server's stream. A long page can hold many of these and only pay for the ones someone is looking at.

What this is made of

Two directories, written by two Python scripts (examples/graph-controls/make_bundle.py and examples/piano/make_bundle.py), each ending in a generated index.js that registers its tag. This page imports those two modules and writes no other JavaScript at all — the markup above is the whole integration.
