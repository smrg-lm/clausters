The three data paths, read by this script and drawn on its own canvas — no widget, no GUI host. A synth writes a control bus (an LFO) and an audio bus (a tone); the audio bus is recorded by the server on request. The page then subscribes to both: BusStream brings the bus as periodic snapshots (the meter), TapStream brings the audio bus as windows of samples (the oscilloscope and the spectrum), and a generated buffer is read in bulk with getSamples and reduced by the wasm peak pyramid into one min/max column per pixel (the waveform). Nothing here computes a number in JavaScript: the trigger that makes the trace stand still, the decibel curve, the peak columns and the correlation all come out of the same shared core the GUI host draws with — so this canvas and a host widget on the same bus show the same picture. Everything runs on the in-page engine: no server process, no socket. Swapping to a --ws server is the one line marked below.
