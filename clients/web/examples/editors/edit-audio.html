edit(file): a take in the audio editor, edited as a list of parts. A SoundFile opens in the audio editor, an application the GUI host holds, in a window of the host's and on an engine of its own; what edit answers is its handler, AudioEditor. The editor reads the file where it is and writes nothing it was handed until it is saved. The take is a list of spans of files, and every edit leaves a new list: a cut puts the span's parts on the clipboard, then removes them; a paste of a copy puts its parts in -- nothing is made; a mix renders the copy added onto the frames it lands on into a file of the editor's working folder, which the list then names; a pencil stroke renders a file the size of the stroke and splices it over the frames it was drawn on; Process -> Reverse renders the selection backwards the same way. So an undo is the list before: it costs the list, not the samples, and a take of an hour cuts and pastes as fast as one of a second. The files a render made are kept while an undo, a redo or the clipboard can still reach them and deleted when none can. In a tab the files are the page's own storage. To check the clipboard across files: copy a selection, add a file with the same channel count and rate, then paste and mix at its cursor. Close the origin and paste again; the copy remains available. Copy another span and undo the paste: clipboard replacement leaves destination history intact. A different channel count is refused; Paste preserves a different rate, while Paste mixed refuses it. The View menu chooses waveform (W), spectrogram (S) or both (B). The three buttons below call the same verbs as the menu. View -> Spectrogram settings opens a panel beside the take: the window's size and shape, the overlap, the frequency scale (Notes names them at the A4 below it), the colours and Normalize bands; editor.setSpectrogram(...) sets the same from the console. Process -> Edit gain envelope selects the curve body, and the vertical ruler reads gain while it is in hand. Drag points, bend a segment, or double-click to add a point. Curve edits keep samples intact. The gain envelope button shows a shaped fade; Apply envelope renders it into a new file and resets the curve to unity. Undo restores both.
Drag to select, then Ctrl+X to cut, Ctrl+C to copy, Ctrl+V to paste at the cursor and Ctrl+Shift+V to mix there. Click to put the position cursor down -- the play cursor goes with it while nothing plays; dragging a selection keeps the position cursor where it was -- and Home and End to put it at the take's first and last frame. Space plays from the cursor to the end of the take, or of the selection, with the play cursor following the sound and going back to the position cursor when the pass ends; a second press stops it there sooner. L switches the loop: looping, the selection -- or the whole take -- plays over and over, and a selection drawn again while it loops is where it loops next: the loop follows the drag, and the sound goes to the new start when the drag is let go. The meter beside the take reads its level while it plays and falls when it stops, and neither a play nor a stop clicks: the editor sounds the take on its own engine, whose output fades in and out with the transport. Wheel to zoom in until each sample is a disc, then Alt+drag to draw. Ctrl+Z and Ctrl+Shift+Z walk the history. Every one of these is also in the menu bar -- File, Edit, View, Transport, Help, each entry with its key -- and the transport and the clipboard are tools under it, which act on the take as the keys do. editor.save() -- or Ctrl+S in the window -- writes the edit back into the file it was opened from, and editor.save({ path }) writes it as another file instead. File -> New file... adds a file not written yet to this editor, as the new file button does; its first save asks where it goes. File -> Open file... uses the host's chooser, which lists only audio files and takes the keyboard: Ctrl/Shift selects several files, and a double click or Enter on a file opens the selection as OK does. Cancel it and open it again: it is back in the last directory gone into, with nothing selected. The independent file list is on the left and View -> Files hides or shows it. Each file keeps its cursor, selection and undo/redo history; closing the last one leaves the editor open with no file, and the editor with no file button opens a second editor that starts that way. A playing file continues while another is shown, with its playhead hidden there. Try File -> New file with two and six channels, then switch back and forth while the original loops: the meter shows the viewed file's channels, with zero levels when another file plays. Return to the playing file to see its live levels again.
The menus and the tools read each action's state from the file in focus: draw in the take, then add a new file -- Edit -> Undo is disabled there, and Ctrl+Z does nothing, until you switch back. Cut, Copy and Delete are disabled with nothing selected, Paste mixed with a copy at another rate, and the View and Edit entries mark the view and the layer in force. With the File -> New file dialog up, Ctrl+Z reaches neither the take nor anything behind the dialog; in its name field it undoes the typing. editor.actions() reads the same readings.
