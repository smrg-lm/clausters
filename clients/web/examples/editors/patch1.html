The patcher, level 1: whole defs wired by buses — built, viewed, heard. editors/patch2.html is level 2 (a single def's internal UGen graph). The two are one directed, typed grammar apart by what a box is: here a box is a whole def and a cord is a server bus; there a box is a UGen and a cord is an internal wire. A GraphPatch is the programmatic level-1 patcher: boxes with typed inlets and outlets, and a cord per outlet → inlet. A cord is a bus, but you never number one: compile runs the shared cord→bus pass and names one. Auto-layout — the host lays every box out itself, sources on top and sinks at the bottom. Dragging a box flows back as "move"; cording (drag an outlet pin onto an inlet, either grab order) flows back as "wire", which is just connect by name — so the picture and the object stay one thing. The patch sits in a scroll workspace: Shift+drag pans, the wheel zooms. The buses are never on screen: an unwired outlet keeps its def's default, so these defs default their bus controls to a spare bus nobody reads, and the hardware output is reached through a terminal def (dac: an inlet, no outlet, its out(0, …) baked in) — a box like any other, not an OUT.
