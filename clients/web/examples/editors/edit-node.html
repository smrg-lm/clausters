edit(node): a running node's controls in a window nobody wrote. A SynthDef declares how each control is drawn where it declares the control -- a range, a step, a warp, a unit -- and edit opens any node of it with a window of those controls, generated by the shared core and kept by the GUI host. A control that declares nothing is drawn too: a conventional name (amp) has its usual range, and any other a range around its default. Drag a slider: the node changes at once, with no round trip through this page. Click the toggle to stop the vibrato. The value beside each control is the server's own text for it. Type in the search field (rate, hz) and only the controls whose name holds it are shown. Change it from here sets the node from this page, and the window follows: the host reads every binding back from the server. The same calls as clients/python/examples/editors/edit_node.py. The script boots a native server with Session.live; a page runs its own engine, Session.embed, which the browser starts only after a click.
