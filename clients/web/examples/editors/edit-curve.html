edit(curve): a break-point curve in a window of its own. The smallest of the three structures edit opens, and the one that shows what the verb is for. There is no composition here — no arrangement, no document, no track. The page builds an Automation, hands it to edit, and reads the edited curve back out of the object it already holds. Drag a point to move it; drag a segment vertically to bend it; Ctrl+click adds or removes one; Ctrl+Z undoes. The second window below is the same curve: an undo stack belongs to the data, so a step in either window walks the one order both of them made. How an edit inverts is the shared crate's. The payload goes in with the curve as it stands and comes back as the curve it now is plus the payload that puts it back — one call, because the inverse has to be read before the edit lands.
