edit(timeline): a roll over a timeline, with no composition under it. The same gesture that edits a track's notes in the multitrack, over a Timeline the page filled — no arrangement, no document, no track. Until now the only way to write a roll's edit back was an aggregate's member list, which needs a tree to be a member of; this is the timeline itself. Drag a note to move it, drag its edge to resize, Ctrl+click to add or remove one, Ctrl+Z to step back. Then press play: the notes are the timeline's, so what sounds is what was drawn. The lane under the grid is the timeline's OSC markers, and it is edited the same way: drag one to move it, Ctrl+click one to remove it, Ctrl+Z to step back. A marker is matched back to its item by its label, which is the address it sends, so the message survives the drag — press the read-back button to see it. Adding one there is refused and says why, because a marker is the message it sends and the lane has no way to type an address: add it in the page instead. A note keeps what the roll cannot draw. Order is the only identity the payload carries, so the i-th note's own Event is edited rather than rebuilt from the five numbers a roll can say — which is what keeps the instrument, and everything else the author put on it.
