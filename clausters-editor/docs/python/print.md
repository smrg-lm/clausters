# print

```
print(*objects, sep=' ', end='\n', file=None, flush=False)
```

Writes the objects separated by `sep` and followed by `end`.

```python
print("a", "b", sep=" | ", end=" !\n")
```

If `Ctrl+D` finds no `.md` with the name it looks for, it shows the `pydoc` help
taken from the live session, so it also works with your own functions and
imported modules.
